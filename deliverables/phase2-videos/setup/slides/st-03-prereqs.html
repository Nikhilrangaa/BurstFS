Prerequisites

A Linux box and four packages.

OS
Ubuntu 22.04 / 24.04
or WSL2 on Windows
(macOS not supported — FUSE3/Linux only)
Packages
sudo apt-get update
sudo apt-get install -y build-essential fuse3
  libfuse3-dev pkg-config
…plus sudo access, and a local NVMe disk if you want real performance
Verify: gcc --version · pkg-config --modversion fuse3
