On real hardware — Azure L8as_v3 transcript (see README)

Provision the NVMe data disk first.

lsblk # find the DATA disk — e.g. nvme1n1, not the OS disk
sudo fdisk /dev/nvme1n1 # n → p → 1 → defaults → w
sudo mkfs.ext4 /dev/nvme1n1p1
sudo mkdir -p /mnt/nvme && sudo mount /dev/nvme1n1p1 /mnt/nvme
⚠
setup/aifs-setup.sh force-formats the first NVMe device it finds — no confirmation.
On many VMs that's the OS disk. Check the device name before running it.
