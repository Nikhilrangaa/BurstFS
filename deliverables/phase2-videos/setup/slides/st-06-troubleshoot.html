Troubleshooting

The four things you'll actually hit.

Stale mount after a crash →  fusermount3 -u /mnt/aifs before relaunching
Empty ls after restart →  known limitation — data is safe; read checkpoints from the backend path
No commit marker →  each checkpoint needs its own directory — no loose files at the mount root
NVMe filling up →  delete old *.orphan.* quarantine dirs; no auto-eviction yet
