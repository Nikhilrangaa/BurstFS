The AIFS idea

Decouple performance from durability.

1 · WRITE
Training writes to a normal directory
Lands on local NVMe — training resumes immediately. No code changes.
→
2 · REPLICATE
Background copy to durable storage
Off the critical path. Your NFS/ANF stays the source of truth.
→
3 · COMMIT
.aifs_committed marker written
Only when every file is safely replicated — complete and trustworthy.
One POSIX mount · local NVMe speed in front · durable shared storage underneath
AIFS is a filesystem layer — any framework that writes files just works
